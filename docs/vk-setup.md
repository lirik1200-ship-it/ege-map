# Уведомления ВКонтакте: настройка сообщества

Серверная часть уже развёрнута (функции `vk-webhook`, `vk-notify`, таблица `vk_subscriptions`). Осталось настроить сообщество и положить ключи в базу.
Telegram-бот на паузе: подписки и отправка выключены на сервере, идентификаторы чатов удалены.

## Что нужно собрать (4 значения)
| Значение | Где взять | Куда записать (ключ в `app_secrets`) |
|---|---|---|
| Ключ доступа сообщества | Управление → Работа с API → Ключи доступа | `vk_group_token` |
| Секретный ключ | придумываете сами | `vk_secret` |
| Строка подтверждения | показывает ВК в Callback API | `vk_confirmation` |
| Номер сообщества (цифры) | адрес `vk.com/club123456789` → `123456789` | `vk_group_id` |

Ключи никому не присылайте, в чат тоже.

## Шаги
1. **Сообщения.** Сообщество → Управление → Сообщения → «Сообщения сообщества»: включить.
   Там же «Настройки для бота» → «Возможности ботов»: включить, добавить кнопку «Начать».
2. **Короткий адрес.** Управление → Основная информация → «Адрес страницы»: задайте, например, `ege_map`.
3. **Ключ доступа.** Управление → Работа с API → Ключи доступа → «Создать ключ», право «Сообщения сообщества». Скопируйте ключ.
4. **Секретный ключ.** Придумайте длинную строку из латиницы и цифр (до 50 знаков).
5. **Запись в базу.** Supabase → SQL Editor → выполните, подставив свои значения (строку подтверждения возьмёте на шаге 6, поэтому сначала выполните без неё и добавьте позже):

```sql
insert into public.app_secrets (key, value) values
  ('vk_group_token',  'ВАШ_КЛЮЧ_ДОСТУПА'),
  ('vk_secret',       'ВАШ_СЕКРЕТНЫЙ_КЛЮЧ'),
  ('vk_group_id',     '123456789')
on conflict (key) do update set value = excluded.value;
```

6. **Callback API.** Управление → Работа с API → Callback API:
   - версия API: 5.199 (или последняя доступная);
   - адрес: `https://ritcwzuelbffwmooxbbp.supabase.co/functions/v1/vk-webhook`;
   - поле «Секретный ключ»: тот же, что в `vk_secret`;
   - ВК покажет «Строку, которую должен вернуть сервер». Запишите её в базу и только после этого нажмите «Подтвердить»:

```sql
insert into public.app_secrets (key, value) values ('vk_confirmation', 'СТРОКА_ИЗ_ВК')
on conflict (key) do update set value = excluded.value;
```

7. **Типы событий** (вкладка в Callback API): включить «Входящее сообщение», «Разрешение на получение сообщений», «Запрет на получение сообщений».
8. **Имя сообщества в приложении.** Сообщите короткий адрес (например, `ege_map`): его нужно вписать в `VK_COMMUNITY` в `app.html`. До этого кнопки «Подключить ВКонтакте» скрыты.

## Проверка
1. Откройте ссылку ученика (`…/app.html?s=…`) и скопируйте длинный код после `s=`.
2. Перейдите на `https://vk.me/ИМЯ_СООБЩЕСТВА?ref=КОД`. Сообщество пришлёт текст согласия с кнопкой «Согласен(на)».
3. Нажмите кнопку: придёт «Готово!».
4. Внесите пробник этому ученику: в личные сообщения придёт карточка.
5. Напишите сообществу «Стоп»: подписка и идентификатор удаляются.

## Как вернуть Telegram (если понадобится)
В `app.html` поставить `TELEGRAM_BOT_ENABLED=true`; в базе выполнить
`insert into public.app_secrets (key, value) values ('telegram_enabled','true') on conflict (key) do update set value = 'true';`
Перед этим нужно будет заново решить вопрос с уведомлением Роскомнадзора о трансграничной передаче.
